# Africa Learns — Edulearn

This project contains a responsive web experience and a mobile counterpart for **Edulearn**.

## Pages
- **Learn**: subject content and lessons
- **Community**: social-media-like engagement
- **Account**: profile and account management

## Structure
- `web/learn.html`
- `web/community.html`
- `web/account.html`
- `mobile/index.html`

## Run
Open `web/learn.html` in a browser to start the web experience.
Open `mobile/index.html` for the mobile counterpart.
